会话粘滞是什么？为什么需要？What is session sticky routing?セッションスティッキールーティングとは何ですか？세션 스티키 라우팅이란 무엇인가요?

会话粘滞基于首条用户消息的 SHA1 哈希，将同一对话的后续请求自动路由到同一模型，防止多轮对话中途切换模型导致上下文断裂或幻觉。30 分钟 TTL 自动过期。Session sticky routing uses SHA1 hash of the first user message to route all subsequent requests in the same conversation to the same model, preventing context breaks. 30-min TTL auto-expires.セッションスティッキールーティングは、最初のユーザーメッセージの SHA1 ハッシュに基づき、同じ会話の後続リクエストをすべて同じモデルにルーティングし、コンテキストの途絶を防ぎます。30 分の TTL で自動的に期限切れします。세션 스티키 라우팅은 첫 번째 사용자 메시지의 SHA1 해시를 기반으로 같은 대화의 모든 후속 요청을 동일한 모델로 라우팅하여 컨텍스트 단절을 방지합니다. 30분 TTL이 자동 만료됩니다.
